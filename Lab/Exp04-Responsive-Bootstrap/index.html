3 — Exercise 3: count the classes

Both finished pages are fetched and parsed here, and every class attribute is counted. Nothing below is typed in by hand.

MeasureBootstrapTailwind
 
counting…

Which is easier to read? The Bootstrap file: card, btn btn-primary and navbar name what an element is, so the markup reads like an outline. The Tailwind file spells out how each element looks — bg-white rounded-xl shadow-md p-6 hover:shadow-lg transition-shadow — which is longer to scan but means the design can be changed without leaving the HTML, and the stylesheet that ships contains only the classes actually used.
