Task 4 — Node.js execution

  
The same files run in a terminal:

  
node script.js
node script2.js
node library.js        # PBL demo
node test-library.js   # 7 assertions on addBook / findBook
node programs.js

  
The browser panels format values the way Node's console.log does
    ([ 'Apple', 'Banana' ], { name: 'John Doe' }), so the two outputs can
    be compared line for line. Node additionally colours them and wraps long objects.
