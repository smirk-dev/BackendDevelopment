1 — The ways CSS reaches a page

Each card below is coloured by a different origin. Open DevTools on any of them and the Styles panel names the file — or says element.style / index.html.

External

A linked .css file

This label is coloured by .from-external in css/style.css, brought in with <link rel="stylesheet">. Reused by every page that links it, cached by the browser.

<link rel="stylesheet" href="css/style.css">
Imported

@import inside a stylesheet

This label's colour is set only in css/tokens.css, which no <link> mentions — style.css imports it. So are all the colour tokens this page uses.

/* first line of style.css */
@import url("tokens.css");
Internal

A <style> block

Coloured by .from-internal, written in the <head> of this file. Applies to this page only; no extra request.

<style>
  .from-internal { color: var(--c-internal); }
</style>
Inline

The style attribute

This paragraph's left rule and the label above are inline: written on the element itself. Highest normal priority, impossible to reuse.

<span style="color: var(--c-inline);">

Two more ways, both external: <link media="print"> loads css/print.css, which applies only when the page is printed (try Print preview — the navigation and buttons disappear and links show their address), and the browser's own user-agent stylesheet, which is why an unstyled <h1> is already big and bold.
