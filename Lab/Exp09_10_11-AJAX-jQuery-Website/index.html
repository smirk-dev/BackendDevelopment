Backend Development · CSFS3008P · Experiments 09, 10 and 11 (combined)

AJAX, XML, JSON, jQuery and interactive web development

The manual treats the three experiments as one project. Its own step-by-step code is kept unchanged in manual/; the three experiments are then built out in full in their own folders, all served by one small Express server.

Contents

  1. Manual walkthrough — the "Student Directory" exactly as the manual builds it: Parts C-D (fetch for JSON and XML) and Parts E-F (jQuery $.ajax for JSON, fetch for XML).
  2. Experiment 09 — AJAX with HTML, XML and JSON: each format with XMLHttpRequest and with fetch(), the failure cases, and POSTing JSON.
  3. Experiment 10 — two jQuery programs: Program 1, selectors, DOM, events and effects; Program 2, jQuery AJAX.
  4. Experiment 11 — Campus Directory, a website in HTML, CSS and JavaScript that loads every page and record with AJAX (Practice Tasks 1-5).
