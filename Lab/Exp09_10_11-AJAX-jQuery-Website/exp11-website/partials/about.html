How it works

  1. The browser loads index.html, site.css and site.js once.
  2. Clicking a navigation link changes the URL hash; site.js hears hashchange and fetches partials/<page>.html into <main>.
  3. Each page then requests its data — JSON, XML or the Express API — and builds the table or cards with textContent, so data is never interpreted as HTML.
  4. Presentation (HTML/CSS), logic (site.js) and data (data/ or the API) stay in separate files: swapping the static file for the backend changed one URL.
