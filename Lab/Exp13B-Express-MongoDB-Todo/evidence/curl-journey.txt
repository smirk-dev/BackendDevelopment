## Protected routes require a valid token
$ curl -X GET /api/todos
{"message":"No token, authorization denied"}
HTTP 401

$ curl -X GET /api/todos -H 'Authorization: Bearer <token>'
{"message":"Token is not valid"}
HTTP 401

## "Logout" - JWT is stateless, so logging out means the client discards the token
# the API keeps no session; once the client drops the token every protected call is 401 again
$ curl -X GET /api/todos
{"message":"No token, authorization denied"}
HTTP 401
