A responsive page with HTML and CSS

No framework: a viewport meta tag, flexbox for the navigation, CSS Grid for the cards and media queries at 480, 768 and 1024px. Resize the window — the label below is written by the active media query, not by JavaScript.

Cards — 1, 2, 3 or 4 columns

Fluid images

max-width: 100%; height: auto — the drawing shrinks with its card and never overflows.

Viewport tag

Without width=device-width a phone renders at 980px and zooms out until the text is unreadable.

Flexbox

The navigation is a flex row on wider screens and a flex column on phones.

Grid

grid-template-columns is redefined at each breakpoint: 1 → 2 → 3 → 4 columns.
