4–6 Why objects need JSON

Storage only keeps strings. Store an object directly and you get its default string form. JSON.stringify turns it into text, JSON.parse brings it back.

7.2 The save / load helper pattern

function save(key, data) { localStorage.setItem(key, JSON.stringify(data)); }
function load(key) { const raw = localStorage.getItem(key); return raw ? JSON.parse(raw) : null; }

Both helpers are on window, so they work from the DevTools console too.
